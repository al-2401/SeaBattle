# Морской бой — записка для сессии

Клон советского игрового автомата на Flutter: перископ, сектор обзора 30°
из ±72°, инерционная наводка, синтезированный звук. Работа идёт в ветке
`claude/flutter-battleship-periscope-607gio`, PR #1 (draft).

## Как над этим работают в две сессии

Проект ведут посменно: днём — облачная сессия Claude Code, вечером —
локальная в desktop-приложении под Windows. Точка передачи одна — GitHub.

- **Первым делом в начале смены:** `git pull`. Другая сторона почти
  наверняка что-то положила в ветку.
- **В конце смены:** коммит и `git push`. Незапушенное в облачной сессии
  умирает вместе с контейнером, а локальное просто блокирует следующую
  смену.
- Обе стороны пишут в одну ветку. Если всё-таки разошлись —
  `git pull --rebase`, история тут линейная и конфликты редки: код
  разложен так, что правки обычно не пересекаются.
- Не оставляй незакоммиченных правок на ночь: `git pull` на них падает.

Планы на будущее — кампания, оболочка в духе Wing Commander, выпуски под
разные страны — лежат в `docs/campaign.md`. Это спецификация, а не
реализация: прежде чем что-то строить оттуда, сверься с ней и обнови её,
если решение изменилось.

## Команды

```bash
flutter pub get
flutter run -d windows            # или -d chrome — так быстрее смотреть
flutter analyze                   # должно быть пусто
flutter test                      # 116 тестов
dart run tool/generate_sounds.dart  # пересобрать assets/audio/*.wav
```

## Устройство

```
lib/engine/   правила игры. Ни одного импорта Flutter — это правило, и оно
              проверяется тестом (test/architecture_test.dart)
  vec2.dart        мир в метрах: +y по носу, +x на правый борт
  geometry.dart    углы; расстояние отрезок–отрезок для попаданий
  periscope.dart   инерционный привод наводки с упорами
  entities.dart    корабли шести классов, торпеды, мины, взрывы
  world.dart       трафик, попадания, боезапас, счёт, очередь звуковых событий
  sight.dart       проекция мира в окуляр (одно фокусное расстояние на всё)
  sound_cue.dart   чем движок называет случившееся
  game_config.dart ВСЕ настройки игры одним файлом

lib/audio/    звук, которого нет в файлах, пока его не сгенерируют
  synth.dart       генераторы, фильтры, огибающие, кодер WAV (чистый Dart)
  sound_bank.dart  рецепт каждого из одиннадцати звуков
  game_audio.dart  воспроизведение за интерфейсом GameAudio; SilentAudio для тестов

lib/ui/       отрисовка и органы управления
  periscope_view.dart  сборка кадра: клип по окуляру, качка, порядок слоёв
  painters/            небо и море, силуэты, следы и взрывы, оптика и сетка
  control_panel.dart   штурвал, кнопка «ТОРПЕДА», стеллаж торпед
  game_page.dart       тикер, клавиатура, жесты, экраны начала и конца
```

## Что стоит знать, прежде чем править

**Слои.** Движок ничего не знает ни о Flutter, ни о звуке: он копит
`SoundCue`, а презентер забирает очередь раз в кадр (`drainCues`). Синтез
тоже чистый Dart — иначе `tool/generate_sounds.dart` не запустится вне
Flutter. Тест `architecture_test.dart` это стережёт.

**Настройки не размазаны.** Скорость торпеды, инерция привода, частота
трафика, поле зрения — всё в `lib/engine/game_config.dart`. Громкости — в
карте `_cueLevels` в `game_audio.dart`. Тембры — числа в `sound_bank.dart`;
после правки обязательно перегенерировать звук, иначе упадёт тест
свежести ассетов.

**Проекция — одна на всё.** `Sight` задаёт разбег пеленгов, посадку цели
под горизонтом и её размер одним фокусным расстоянием. Волны и мысы живут
в мировых координатах и проецируются той же оптикой — отсюда параллакс при
повороте. Не рисуй ничего «на глаз» в экранных координатах.

**Высота оптики (`eyeHeight`, 132 м) — намеренное враньё.** Честный
перископ сплющил бы все дистанции в 20 пикселей под горизонтом. Это
аркадное преувеличение, а не баг.

**Петли звука.** Частоты подогнаны под длину петли (`fitToLoop`), чтобы
кроссфейд смешивал совпадающие по фазе куски. Поменяешь длину петли —
пересчитай частоты, иначе на каждом повторе будет провал громкости.

## Тесты

116 тестов, и они настоящие: механика и геометрия столкновений, проекция,
синтез (форма, спектр, стык петель, кодер WAV), свежесть сгенерированных
ассетов, звуковые события, отрисовка во всех состояниях сцены, вёрстка на
телефоне, архитектурные границы. Виджет-тесты подставляют `SilentAudio` и
`FakeAudio` — к звуковому устройству не ходят.

Новый код держи на этом же уровне: тест должен проверять поведение, а не
пересказывать реализацию. Избегай привязки к конкретной
последовательности `math.Random` — посевы меняются от любой правки логики.

## Платформы

В репозитории `web`, `android`, `linux`, `windows`. Для Windows нужна
Visual Studio 2022 с рабочей нагрузкой C++; для Linux `audioplayers`
требует заголовки GStreamer. macOS/iOS добавляются командой
`flutter create --platforms=macos,ios .`.
