# Морской бой

Клон советского игрового автомата «Морской бой» на Flutter — не плоская 2D‑аркада,
а имитация перископа: круглая оптика, узкий сектор обзора и тяжёлый привод наводки,
который продолжает идти по инерции после того, как вы отпустили штурвал.

```
        ┌──────────── ПЕЛЕНГ Л15 ─────────────┐
        │   ▁▁▂▂▃  силуэт транспорта  ▃▂▂▁▁   │
        │ ──────────┼──────────────────────── │   горизонт качается,
        │           │  след торпеды           │   сетка прицела — нет
        └─────────────────────────────────────┘
```

## Что даёт «тот самый» вайб

**Перископ, а не камера.** Всё рисуется через прямолинейную проекцию с одним
фокусным расстоянием (`lib/engine/sight.dart`): оно же задаёт, насколько далеко
друг от друга расходятся пеленги, насколько ниже горизонта сидит цель на данной
дистанции и какого размера её рисовать. Гребни волн и далёкие мысы живут в мировых
координатах и проецируются той же оптикой, поэтому при повороте ближняя зыбь
проносится мимо, а горизонт почти стоит — это и читается как вращение.

**Ограниченный обзор.** В окуляр видно 30° из сектора ±72°. Цель, которую вы
слышали пять секунд назад, придётся искать заново — сверху идёт лента пеленгов
с отметками «Л15 / НОС / П15», по ней и ищут.

**Инерция наводки.** Штурвал не задаёт пеленг, он подаёт момент на тяжёлый
демпфированный привод (`lib/engine/periscope.dart`): разгон около секунды, выбег
после отпускания, удар в упор с отскоком и красной лампой «УПОР». Упреждение
приходится брать заранее — прицелиться «точно сейчас» невозможно.

**Торпеда идёт долго.** 430 м/с, ход до 3400 м: до цели на 2 км торпеда идёт около
пяти секунд, и стрелять надо туда, где корабль будет. Пеленг торпеда берёт
механический, от привода, а не от картинки — качка бьёт по изображению, но не по
залпу. Мины на пути подрывают торпеду и съедают выстрел.

**Звук синтезирован, а не записан.** Ни одного скачанного сэмпла: все
одиннадцать звуков собираются кодом из качающихся генераторов, фильтрованного
шума и огибающих (`lib/audio/synth.dart`, рецепты — в `sound_bank.dart`), что
даёт ровно тот электронный тембр, который был у звуковой платы автомата.
Главный из них — гул привода наводки: его громкость и высота идут за угловой
скоростью перископа, так что инерцию слышно не хуже, чем видно. Плюс шипение
воздуха при пуске, винты торпеды в воде, взрывы, всплеск промаха, лязг
перезарядки, удар в упор, далёкий гудок парохода и отбой в конце патруля.
Море и корпус гудят фоном. Кнопка «ЗВУК» в шапке или клавиша `M` — тишина.

## Управление

| | |
|---|---|
| `←` `→` или `A` `D` | наводка (удерживать — привод разгоняется) |
| `ПРОБЕЛ` | залп |
| `R` | заново |
| `M` | звук вкл/выкл |
| штурвал внизу / протяжка по экрану | наводка на сенсоре |
| красная кнопка / тап по оптике | залп |

Счёт зависит от класса цели и дистанции: далёкий выстрел ценнее. За попадание
возвращают торпеду в стеллаж. Патруль кончается, когда израсходован боезапас.

## Запуск

```bash
flutter pub get
flutter run            # или: flutter run -d chrome
flutter test           # 98 тестов: механика, оптика, синтез звука
```

Пересобрать звук после правки рецептов:

```bash
dart run tool/generate_sounds.dart
```

Единственная внешняя зависимость — `audioplayers`, и только ради
воспроизведения. Для сборки под Linux ему нужны заголовки GStreamer
(`sudo apt install libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev`);
для web и Android ничего доставлять не надо.

## Устройство

```
lib/engine/    чистая механика, без единого импорта Flutter — вся под тестами
  vec2.dart        мировые координаты: +y по носу, +x на правый борт
  geometry.dart    углы и расстояние отрезок–отрезок (защита от протыкания цели)
  periscope.dart   инерционный привод наводки с упорами
  entities.dart    корабли, торпеды, мины, взрывы
  world.dart       правила: трафик, попадания, боезапас, счёт, звуковые события
  sight.dart       проекция мира в окуляр
  game_config.dart все настройки одним файлом

lib/audio/     звук, которого нет в файлах, пока его не сгенерируют
  synth.dart       генераторы, фильтры, огибающие, кодер WAV
  sound_bank.dart  рецепт каждого звука
  game_audio.dart  воспроизведение; SilentAudio для тестов
tool/generate_sounds.dart  пишет assets/audio/*.wav

lib/ui/        отрисовка и органы управления
  periscope_view.dart   сборка кадра: клип по окуляру, качка, слои
  painters/             небо и море, силуэты, следы и взрывы, оптика и сетка
  control_panel.dart    штурвал, кнопка «ТОРПЕДА», стеллаж торпед
  game_page.dart        тикер, клавиатура, жесты, экраны начала и конца
```

Столкновения считаются как расстояние между двумя отрезками — путём торпеды за
кадр и корпусом от кормы до носа, — поэтому быстрая торпеда не проскакивает
сквозь катер между кадрами, а лагом корабль поразить легче, чем в нос.
